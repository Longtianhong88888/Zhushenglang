1. **只做多头排列中的票**：72 只里优先强势多头 + 回踩企稳两组；破位/空头一律不参与。

2. **买点优先顺序**：买点2（回踩MA10企稳）> 买点1（T0次日确认）> T0当日不追。

3. **仓位**：单票≤1/3，最多 3 只并行；综合分 Top 优先。

4. **止损铁律**：买入价-5% 盘中低点触发即走；持仓 5 日不涨时间止损。

5. **止盈**：盘中最高点到收盘回落 8% 用收盘价判断（不是盘中低点）。

6. **防追高**：10 日涨幅≥150% 不进买点；20 日高点回撤>30% 的暴跌票只做反转二次确认。
