# 项目经验：A 股主升浪量化信号跟踪系统

**角色**：量化研究 + 全栈开发（Python）
**周期**：2026-07 至 2026-08 持续迭代上线
**状态**：线上运行中（腾讯云 + 每日自动流水线 + 盘中实时盯盘）

## 一、项目概述

面向 A 股主升浪行情的**量化信号研究 + 实时盯盘系统**：自建全市场日线数据库，
聚焦 122 家"行业卡点企业"（覆盖 AI 硬件/半导体/存储/机器人/商业航天/自动驾驶/
有色/创新药 + 十五五六张网等 13 个方向），实现信号回测、财务评估、综合评分、
每日报告、网页实时盯盘与桌面应用全链路，并部署上线。

## 二、核心工作与量化成果

### 1. 数据基建（无付费数据源）
- 自建全市场日线库（zzshare 公开数据，2021 年起，约 5900 只 A 股、680 万行），
  交易日历/股票名册/增量更新全自动；
- 全部行情与基本面迁移到**腾讯 + 东方财富公开接口**，去除同花顺 API Key 依赖：
  实时快照（单请求批量 50 只）、日K/分时、财务指标、涨停池、龙虎榜全覆盖；
- 财务评估按"公告日期 ≤ 信号日"取已披露报告期，**杜绝未来函数**；
- 接口限流处理：双主机回退 + 分级缓存 + 失败降级保留旧数据，页面永不闪空。

### 2. 信号模型与回测（历史 3 万+ 信号）
- T0 主升信号：均线多头 + 创 20 日新高 +（涨幅≥5% 且量比≥1.5）或（涨停且量比≥1.0），
  全市场回测 2022 起 595 个信号（122 家卡点范围）；
- 规则改进：新增涨停量比门槛（剔除一字板/缩量涨停）、防追高阈值放宽、
  板块退潮保护（同行业≥3 只且均价破 MA10 暂停买点）、买点 2 企稳质量过滤；
- 综合评分 = 40% 财务 + 30% 信号 + 30% 产业地位，输出观察池与买点提示。

### 3. 量化研究（为模型提供依据，全部无未来函数）
| 研究 | 结论 |
| --- | --- |
| 买点胜率研究 | 3 万信号胜率 31.1%（盈亏比驱动），据此改进 T0/买点规则 |
| 暴跌反转研究 | 回撤≥30% 后放量涨停 + 次日确认；卡点口径 +5 日胜率 **63.2%**、均收 +3.58% |
| 起涨特征量化 | 72 只卡点 1074 段起涨画像：深蹲约 -12% 后放量 1.4 倍启动；巨量反而不优 |
| 全市场启动规则 | r7m（超跌+温和量+市场共振）5 日胜率 63.4%、PF 2.71；r9（强市场）71.1%、PF 4.90；增强版 r9A（前5日<0 干净首阳）5 日胜率 **83.0%、PF 14.9** |
| **启动加仓投资模型** | 前置打底仓 → T+1 站上 MA10 次日加仓（2:1）→ 止损-7%/高点回落10%止盈/10日时间止损/涨停<50 退潮清仓；**r9A 完整模型 5,197 笔：胜率 77.2%、均收 +10.65%、PF 10.47**；2022/2024/2025 年胜率 77-83% |

### 4. 实时盯盘系统（秒级更新）
- 3 秒轮询腾讯实时行情，网页端 8 列排版（代码/名称、现价、分时缩略图、涨跌幅、
  量比、分组、买入信号、卖出信号），手机自适应；
- 盘中提醒仅针对买卖信号：止损/高点回落/破位/企稳买点/启动模型信号，10 分钟限频；
- "今日买入卖出信号卡"动态更新：持仓 + 待买标的盘中随时可见，14:30 后评估企稳买入；
- 启动加仓模型接入盯盘页：122 家卡点实时扫描 r7mA/r9A（"明日开盘打底仓"提醒），
  全市场涨停家数 60 秒缓存，跌破 50 触发退潮保护清仓警告；
- 标的详情页：日K 蜡烛图 + 分时线，5 分钟预热缓存，点击代码即开即看。

### 5. 每日流水线与报告
- 每日 17:30 定时：更新行情 → 回测 → 财务评估 → 综合评分 → 跟踪报告 →
  仪表盘/网页/复盘自动同步（全自动，失败不阻塞）；
- 输出 Markdown + CSV + Excel（QuantDark 暗色主题仪表盘）+ 单文件网页门户
  （KPI/实时盯盘/当日复盘/每日报告四入口），Nginx 托管 + Basic Auth。

### 6. 部署与工程化
- 腾讯云 CVM（Ubuntu）部署：cron 每日流水线 + systemd 常驻盯盘服务 +
  Nginx 静态托管，公网手机可访问；全量数据打包上传（656MB → 256MB）免服务器下载；
- macOS PyQt5 桌面应用打包（.app，含内置行情与模板），Windows 版 GitHub Actions
  自动构建；
- 64 项单元测试全绿（信号/回测/盯盘/反转/起涨/策略/仪表盘），数据无前视断言；
- 踩坑记录与修复：同花顺依赖迁移、root/ubuntu 权限、Nginx 默认站点抢占、
  小样本回测空表崩溃、东财限流降级等，均已沉淀到项目记忆。

## 三、项目难点与解决方案

1. **零成本数据源稳定可用**：腾讯/东财公开接口限流频繁，通过双主机回退、60-600s
   分级缓存、失败保留旧数据 + 错误日志，保证盯盘页不闪空；
2. **回测无前视**：财务按公告日取报告期、信号只用当日可得数据，研究结论诚实标注
   （如 2026 年市场环境下模型胜率衰减至 40% 左右，明确写入报告，不粉饰）；
3. **实时性**：快照批量从 41 次请求优化为 1 次（0.6s），盯盘 3 秒轮询 + 分时
   缩略图累积，页面 3 秒增量刷新不整页跳；
4. **模型可解释**：所有规则参数来自全市场分桶回测（如量比 1~2 优于巨量、
   止损 -7% 优于 -5%），每个结论附样本量与逐年稳定性。

## 五、一句话总结

从零搭建了一套"数据 → 回测 → 研究 → 信号 → 盯盘 → 报告 → 部署"完整闭环的
A 股量化跟踪系统，核心启动加仓模型全市场回测 5,197 笔、胜率 77.2%、盈亏比 10.5，
并已在服务器与手机端持续运行。
