# 启动加仓投资模型说明书（v1 · 2026-08-13）

> 模型定位：**超跌首阳 + 市场共振**的短线波段模型。前置特征打底仓 → T+1 判定
> 加仓 → 止损/止盈/时间止损/市场退潮保护。
> 回测口径：全市场 5907 只（2021-01-01 ~ 2026-08-12），无未来函数，
> 每笔成交费用 0.1%；报告见 `output/reports/启动加仓模型_<date>.md`，
> 命令 `mainrise strategy`。免责：仅研究，不构成投资建议。

## 一、启动信号（前置特征，全部当日可得）

1. 20 日回撤 ≥ 15%（现价较前 20 日最高点）
2. 当日涨幅 ≥ 5%（大阳线）
3. 温和量比 1.0 ~ 2.0（巨量启动反而差，情绪高点/出货嫌疑）
4. 前 5 日涨幅 < 0（**干净首阳**：信号日是反弹第一天，不是第 2-3 天）
5. 市场环境：全市场涨停家数 ≥ 90（标准模式 r7mA）/ ≥ 130（强市场模式 r9A）
6. 剔除 ST、停牌；若前 10 日涨幅已 ≥ 150% 不参与（防追高）

## 二、建仓（底仓 + 次日判定加仓）

| 时点 | 动作 | 仓位 |
| --- | --- | --- |
| 信号日 T 收盘 | 确认信号成立 | — |
| T+1 开盘 | **打底仓** | 计划仓位的 2/3（单票总仓 ≤ 1/3 总资产） |
| T+1 收盘 | 判定：收盘站上 MA10 且未触发退出？ | — |
| T+2 开盘 | 满足判定 → **加仓**（底仓:加仓 = 2:1）；不满足则不加 | 计划仓位的 1/3 |

加仓只做"乘胜追击"：历史回测中加仓不提升单笔胜率/均收（r9A：77.2%/+10.7% vs
仅底仓 77.9%/+11.2%），其价值是**放大盈利交易的仓位**；约 27% 的交易触发加仓。

## 三、退出纪律（止盈止损点）

| 规则 | 参数 | 触发口径 |
| --- | --- | --- |
| 止损 | 加权均价 **-7%** | 盘中低点触发即出（两笔持仓按金额加权成本） |
| 止盈 | 持仓最高价回落 **10%** | **收盘价判定**（不是盘中低点，防止假回落误平仓） |
| 时间止损 | **10 个交易日** | 到期收盘卖出 |
| 市场退潮保护 | 全市场涨停家数 **< 50** | 次日开盘清仓（模型核心风控，约 66% 交易由此退出） |

> 参数说明：超跌反弹票波动大，-5%/回落8% 会被震荡扫出；-7%/回落10% 把
> 5 日胜率从 68% 提到 77%、PF 6.05 → 7.65。与 T0 趋势模型的 -5%/8% 纪律不同，
> 两套模型各用各的参数。

## 四、仓位与组合管理

- 单票 ≤ 1/3 总资产；同时持仓 ≤ 3 只
- r9A（强市场）信号质量最高：胜率 77.2%、均收 +10.7%、PF 10.5；优先开仓
- r7mA（标准）信号次之：胜率 64.0%、均收 +7.1%、PF 5.1
- 市场涨停家数跌破 90 时停止开新仓（信号本身要求 ≥90/130，天然节流）
- 2026 年环境衰减：r9A 胜率约 37-40%、均收接近 0 → 建议半仓运行、只做
  强市场信号、10 日短线兑现

## 六、退出原因（r9A，验证纪律执行）

- 退潮：3,446 笔（66%），均收 +14.4% —— 市场冷却时带走利润，是收益主要来源
- 时间：723 笔（14%），均收 +10.0%
- 止损：665 笔（13%），均收 -7.1% —— 单笔亏损被严格控制在 -7% 附近
- 止盈：363 笔（7%），均收 +8.6%
