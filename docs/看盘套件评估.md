# GitHub 现成看盘套件评估（2026-08-13）

> **状态：已按推荐接入 KLineChart**（2026-08-13，见文末"接入实录"）。

## 一句话结论

GitHub 上有成熟的**组件级**看盘套件（K 线/分时渲染库），但没有值得整套替换我们门户的成品级看盘 App（完整行情+自选+盯盘的现成 Web 应用，star 大都在 20 以下且不适合挂到 Nginx 静态页）。

推荐：**KLineChart**（主选）或 **lightweight-charts**（备选），以本地静态 JS 方式接入 `/stock/<code>` 详情页，替换现在手绘 SVG 的 `drawK`。两个都是 Apache-2.0，商用无合规风险，零 CDN 依赖，符合项目"单文件自包含 HTML + Nginx 静态托管"的架构。

## 与我们的约束匹配

1. **零构建、单文件自包含**：四个库都有 UMD 单文件版，下载到项目里随页面输出即可，无需 npm/webpack；Nginx 静态托管不受影响。
2. **数据已是 JSON**：`/stock/<code>/data` 已返回前复权日 K（open/high/low/close/volume/date）与分时，套件只做渲染，后端零改动。
3. **必须保留的自定义标注**：T0/T1/T2 红箭头、平仓绿箭头、MA5/10/20/60、线性回归通道、支撑/压力连线、十字光标 OHLC 提示、量能、红涨绿跌、手机自适应、默认近 60 根 + 放大/缩小/全部/平移 + 滚轮缩放。
4. **更新频率**：日 K 5 分钟缓存、分时 10 分钟，量能极小，图库无压力。

## 逐个点评

### KLineChart（推荐主选）

专业 K 线库，零依赖，`createOverlay` 可自由画线段/文本/箭头，正好覆盖回归通道、支撑压力、T0/T1/T2/平仓标注；缩放平移十字光标内置，移动端触摸也支持；v10 最新（2026-08 仍活跃维护），单文件 228KB。接入成本最低，且保留了现有功能的全部语义。

### lightweight-charts（备选）

社区最大、交互最顺滑（TradingView 手感），单文件最小（~193KB）。但自定义标注走 v5 primitive/plugin API，回归通道和信号箭头要额外写插件，工作量比 KLineChart 大；若以后想强化"专业终端感"可考虑。

### HQChart（功能最强，现阶段不推荐）

唯一真正"通达信式"的套件：筹码、画图工具、指标语法都内置，体验最完整。但仓库 926MB、实际 JS 也是多文件体系，初始化 API 与我们的 Python f-string 生成 HTML 风格磨合成本高，后续维护（版本升级/换机器）风险最大。留作"以后想要高级画图功能"的备选。

### ECharts（不推荐做主图）

大厂标配、标注支持最好（markPoint/markLine 声明式就能画箭头），但它是通用图表库不是看盘库：十字光标/缩放手感弱、体积最大。现有仪表盘/复盘页如果要加普通图表可以顺手用，主 K 线不推荐。

## 推荐接入步骤（以 KLineChart 为例）

1. 下载 `klinecharts.min.js`（v10.0.2，固定版本）到 `mainrise/resources/`，打包脚本 add-data；或放 `output/web/static/` 由 Nginx 直接托管。
2. `mainrise/stockpage.py` 的 `PAGE_JS` 中 `drawK` 改为初始化 KLineChart：
   - 数据转换：`{timestamp, open, high, low, close, volume}`；
   - 内置 indicator MA(5/10/20/60) + VOL；
   - T0/T1/T2/平仓：overlay 线段+文本（红/绿箭头语义不变）；
   - 回归通道、支撑/压力：`createOverlay` 画线段；
   - 十字光标/OHLC 提示用内置 tooltip 自定义；
   - 现有按钮语义映射：默认近 60 根 → `setZoom`；放大/缩小/全部/更早/更近 → zoom/scroll API；滚轮缩放内置。
3. 分时图 `drawT` 可继续用现有 SVG（已稳定），或换成 KLineChart 的 timeline 类型，二选一不影响 K 线。
4. 本地 5 档窗口验证（桌面/手机）+ 34 项测试全绿后，rsync `mainrise/stockpage.py` + 静态资源到服务器，`systemctl restart mainrise-monitor`。
5. 更新 AGENTS.md 与本文档的"已接入"状态。

## 风险与边界

- 图库不改变数据源，腾讯/东财免费接口限流照旧（现有缓存/降级机制不变）。
- 不引入任何 CDN（国内访问不稳），JS 必须随仓库/打包产物分发。
- 版本固定后不随意升级；lightweight-charts v4→v5 API 不兼容，KLineChart v9→v10 也有差异，升级前先看 CHANGELOG。
- 许可证均为 Apache-2.0，保留 LICENSE 声明即可。
