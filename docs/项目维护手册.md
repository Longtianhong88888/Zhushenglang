## 0. 三句话看懂项目

- 这是一个 A 股主升浪信号系统：**大牛模型**（固化版，唯一实盘跟踪）追踪
  全市场（排除 301/688 约 4262 只）中的**固定热主题**（AI硬件/半导体/存储），
  跑"信号 → 评分 → 每日买点 → 盘中点火 → 实时盯盘 → 收盘确认"全链路。
- 数据**全部来自免费公开接口**（腾讯行情 + 东方财富财务/涨停/龙虎榜/资金流 +
  腾讯 m5 分钟归档），**无付费 API、无 API Key 依赖**；回测与研究全部**无未来函数**。
- 已上线腾讯云（每日 17:00 自动流水线 + 盘中 10 分钟点火检测 + 3 秒实时盯盘 +
  **DSH 手机 AI 对话**），另有 macOS 桌面应用与 Windows 自动打包。

## 1. 核心模型规则（业务口径，勿随意改）

### 1.1 大牛模型（固化版，2026-08-14/15 用户确认，唯一实盘跟踪）

> 回测 2021-08 ~ 2026-08-14：**+998% / 年化 +56% / 最大回撤 -36% / PF 3.45 /
> 胜率 46% / 107 笔**（排除 301/688 后口径；2026-08-15 审计修正，原 +1108% 含
> 301 不可交易股虚增已剔除）。命令 `mainrise bigbull`。

| 项 | 规则 |
| --- | --- |
| 追踪范围 | **全市场**（排除 ST/停牌/301/688，约 4262 只；2026-08-15 由卡点 97 只放宽） |
| 热主题 | **固定三主题**：AI硬件 / 半导体 / 存储（研究证明固定>动态，勿放开） |
| 入场 | 信号日（T0）确认：**热主题 且 90 日内 T0 信号 ≥3 且 评分 ≥2** |
| 大牛评分 | 热主题 +1 ｜ 90日T0≥3 +1 ｜ 创60日新高且10日<30% +1 ｜ 链长≥4 +1 |
| 买入价 | **信号日未涨停 → 尾盘收盘买；一字涨停 → T+1 开盘买**（2026-08-15 口径） |
| 同日多信号 | **只买评分最高 1 只**（Top1，2026-08-15 固化） |
| 仓位 | 单票 1/3 仓，最多 3 只并行 |
| 退出 | 收盘跌破 MA20 **或** 买入后连续 8 个交易日未收复买入价（洗盘止损，先于 MA20） |
| 弱市降档 | 大盘等权 20 日涨幅 ≤-5%（杀跌区）不新开仓 |
| 追高禁入 | 信号日 20 日涨幅 ≥60% **且** 大盘 20 日 ≤0% → 禁入（透支+弱市双条件） |
| 涨跌停约束 | **一字板**（最高=最低=涨停/跌停价）才不可成交；普通涨停可成交（2026-08-15 审计 M9） |
| 费用 | 0.2%/笔（双边） |

- **常量位置**：`mainrise/bigbull.py`（SCORE_MIN/EXIT_MA/WASH_EXIT_DAYS=8/
  MARKET_SCOPE="all"/TOP1_DAILY=True/BAN_OVERBOUGHT_WEAK=True）。
- **参数稳健性**：walk-forward 验证通过（`mainrise/walkforward.py`）——洗盘 8 天/
  Top1 在训练段（2021-2023）已优于基线，非全期过拟合。

### 1.2 T0 信号（大牛模型依赖的信号计算）

| 条件 | 值 |
| --- | --- |
| 均线 | MA5 > MA10 > MA20（多头排列） |
| 突破 | 创 20 日新高 |
| 放量 | （涨幅 ≥5% 且 量比 ≥1.5）**或**（涨停 且 量比 ≥1.0） |

- 缩量涨停/一字板不计（`MIN_VR_LIMIT=1.0`，剔除买不进的一字板信号）。
- 常量：`mainrise/signals.py`（MIN_CHG=5, MIN_VR=1.5, MIN_VR_LIMIT=1.0）。

### 1.3 盘中点火检测（`mainrise ignite5`，候选池 5 分钟资金进攻）

- **跟踪范围（2026-08-15 用户明确）= 大牛候选池**（`bigbull_cands.json` 的
  cands，已满足买入条件；当前 3 只 000938/003031/603662，动态变化）。
- **点火 = 单根 5 分钟量 > 2×近5日单根均量 且 当日涨幅 ≥3% 且（破前20高 或 涨幅≥5%）**。
- 盘中每 10 分钟 cron 检测 → 飞书推送 + 门户买卖点卡片"🔥 盘中点火信号"。
- **非交易日保护**：周末/节假日不检测、落盘空 signals（2026-08-15 修复）。
- **基准对齐（2026-08-15 审计 H1 修复）**：prev_close/hi20 按 5 分钟最新交易日
  与日线最新日期是否相等取 iloc[-1] 或 iloc[-2]，避免盘中滞后一日。
- **轻量加载（审计 M1 修复）**：只读候选代码近 40 日按日文件（0.2s/120 行），
  不再 `load_all_panels()` 全量 700 万行（防 OOM）。
- 输出：`output/state/ignite5.json` + `output/reports/点火信号_<date>.md`。

### 1.4 框架模型（用户维护中，研究用，非实盘跟踪）

- **启动加仓**：超跌首阳（r7mA/r9A）+ 市场共振 → T+1 开盘底仓 2/3 → 站上 MA10
  T+2 加仓 1/3；止损加权均价 -7%、止盈高点回落 10%、时间止损 10 日、涨停<50 退潮清仓。
- **暴跌反转**（`mainrise reversal`）：20 日高点回撤 ≥30% → 首次放量涨停 → 确认买入。
- **B3/二波**：均线粘合爆量突破（B3）→ 回踩二波加仓；止损 -4%、止盈高点回落 8%。
- 详情见 AGENTS.md"框架"段；这些只做研究/参考，买卖点卡只出大牛模型。

## 2. 数据与数据源（全部免费公开接口）

### 2.1 本地日线库（主数据源）

- 位置：`data/zzshare_daily/YYYYMMDD.csv`（每交易日一个全市场文件，约 5543 只）。
- 列：date, code, open, high, low, close, limit_price, low_price, turnover,
  amount, pct_chg, prev_close, is_st, is_paused, volume。
- 起点 2021-01-01；zzshare **当日日线收盘后才发布**（17:00 流水线含数据新鲜度
  校验：未发布则每 10 分钟重试最多 1 小时）。
- 交易日历 `data/trade_dates.csv`、股票名册 `data/stock_list.csv`。

### 2.2 5 分钟归档（`mainrise m5data`，点火检测数据源）

- 位置：`data/m5daily/<code>.csv`（腾讯 m5，110 只卡点全量归档 + 候选池）。
- 字段：datetime, open, close, high, low, volume（量×100 手→股）。
- 每日 17:00 流水线增量归档；月度 `mainrise m5optimize` 优化点火阈值。

### 2.3 实时行情（腾讯）

- 快照：`qt.gtimg.cn` 单请求批量 50 只（GBK），`mainrise/snapshot.py`。
- 日K/分时：腾讯 fqkline / minute，东财兜底；`mainrise/stockpage.py`。

### 2.4 财务评估 / 涨停池 / 龙虎榜 / 资金流（东财，无 API Key）

- 财务：`RPT_LICO_FN_CPD` + `RPT_DMSK_FN_BALANCE`（无前视，按公告日≤信号日）。
- 涨停池：`getTopicZTPool`（仅当日；历史用本地日线）；龙虎榜：`RPT_DAILYBILLBOARD_DETAILSNEW`。
- 资金流：push2.eastmoney.com（免费接口会随机断连 → 双主机回退 + 缓存 + 失败保留旧数据）。

### 2.5 缓存策略（限流对策）

| 数据 | 缓存 |
| --- | --- |
| 全市场涨停家数（盯盘） | 60s |
| 概念板块资金流 | 600s（10 分钟） |
| 标的详情日K/分时 | 600s |
| K线预热 | 全量 5 分钟 / 热标的 60s |
| 东财资金流缓存 | `output/web/.flow_cache.json`（失败沿用+标注） |

## 7. 已知坑与决策记录（排查先看这里）

| 问题 | 结论/修复 |
| --- | --- |
| DSH 手机 400 | 手机用 http 访问 3081 → nginx 497→301 跳转 https |
| DSH /api 403 | nginx 反代 Host 必须 `$http_host`（含端口），否则 trusted-host 不匹配 |
