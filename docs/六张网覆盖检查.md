## 二、逐网明细

### 1. 算力网 —— ✅ 覆盖最完整

环节映射（名单内）：光模块/CPO（中际旭创、新易盛、天孚通信）、AI 服务器 PCB

算力租赁（润泽、数据港、奥飞、中贝、云赛智联）、算电协同（中恒电气、科华数据、

## 三、结论与建议

1. **覆盖结构**：1 张完整（算力网）、2 张部分（通信网/电网）、**3 张空白
   （水网/城市地下管网/物流网）**——模型目前偏"算力+"单极，传统基建三张网
   完全没有。
2. **优先补缺顺序**：①水网+管网（管材可共用，一次补两张）→ ②物流网 →
   ③新型电网 → ④通信网补缺；合计约 29 家候选
   （见 `docs/六张网缺口候选.csv`，pos 均待评估）。
3. 若并入，名单 93 → 约 122 家；backtest/reversal/track/monitor 自动扩围，
   盯盘轮询量同步增加。
4. 注意：六张网以基建/公用事业为主，走势属性与"算力主升"差异大，建议先按
   r7mA/r9A 启动模型验证其信号质量再决定仓位权重。
