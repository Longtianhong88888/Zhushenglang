# 均线粘合爆量突破：T0 信号时点前移研究（2026-08-14）

> 用户洞察：现 T0 信号靠后——它要求"均线多头排列"（MA5>MA10>MA20），等排列
> 成立时均线往往已经发散、股价已在半山腰/高点，进去容易站岗。要抓的是**均线
> 粘合位置、放量阳线同时上穿 5/10/20 日均线（均线刚发散）**的那一根。

## 一、验证：现 T0 的"站岗"问题是真的

卡点名单 2022 起，现 T0 信号（多头排列+创20日新高+涨≥5%量比≥1.5/涨停）：

| --- | --- | --- |
| n | 1,935 | 1,139 |
| 10日胜率 | 43.2% | 43.5% |
| 10日均收 | +0.86% | +0.97% |
| PF | 1.16 | 1.20 |
| P≥10% | 20.1% | 19.5% |
| **10日内回撤>5% 占比** | **69%** | **64%** |
| 10日最深回撤均值 | -9.5% | -8.9% |

64~69% 的信号 10 日内浮亏超 5%，最深回撤均值 -9%——**确实大量站岗**。

## 二、新信号：粘合爆量突破（B3）

```
B3（均线粘合爆量突破）：
  粘合：MA5/MA10/MA20 最大偏离 ≤ 3%（spread ≤ 3%）
  阳线：close > open
  放量：量比 ≥ 2.0（vs 前5日均量）
  涨幅：≥ 1%（爆量阳线即可，不要求大涨——8/6 秦安仅 +1.93% 也命中）
  上穿：close 同时站上 MA5/MA10/MA20
  低位：距 60 日低点 < 30%（排除高位）
  确认：次日低点 ≥ 信号日低点 → 次日开盘买入
```

秦安 603758 8/6 逐项命中：粘合 2.85% ✓ 阳线 ✓ 量比 2.75 ✓ 涨幅 +1.93% ✓
上穿 ✓ 低位 ✓ 确认 ✓ → 次日开盘 9.45，5 日 +47.6%。

**B3 全面优于现 T0**：胜率 +7.5pp、均收 +0.46pp、PF 1.20→1.48、站岗大幅减少

**唯一权衡**：P≥10% 从 19.5% 降到 15.2%——粘合突破抓不到少数"均线已发散还在
狂奔"的大牛（发散信号的 P≥10% 更高）。这是"更早、更稳"与"更强、更靠后"
的取舍：B3 负责启动前夜，现 T0 可保留为"确认后追强"的第二信号，两者互补。
