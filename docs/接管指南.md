**DSH 运维白名单**（手机对话里让 AI 执行，sudo 仅限这些）：
- `sudo upgrade_dsh.sh --check|--upgrade` — DSH 升级

`/etc/dsh-web.env`（换 key：改文件后 `systemctl restart dsh-web`）。

## 5. 新电脑接管步骤

```bash
# 1) 克隆代码
git clone git@github.com:Longtianhong88888/Zhushenglang.git
cd Zhushenglang

# 2) 建虚拟环境（服务器用 requirements-server.txt）
python3 -m venv venv
venv/bin/pip install -r requirements.txt

# 3) 恢复数据（二选一）
#    a) 从服务器打包（推荐，快）：
#       服务器上跑 deploy/package_data.sh → scp build/server_data.tar.gz → 解压
#    b) 或联网重建：
venv/bin/python -m mainrise.cli init

# 4) 验证
venv/bin/python -m unittest discover -s tests   # 176 项应全绿
venv/bin/python -m mainrise.cli bigbull          # 应输出 +998% 口径报告
```

**服务器 SSH（需要 pem）**：
```bash
chmod 600 /path/to/Zhushenglang.pem
ssh -i /path/to/Zhushenglang.pem ubuntu@129.28.95.59
```

**数据同步方向**（重要）：
- 代码改完 → 推 GitHub → 服务器 `rsync` 同步（见维护手册 §6.6）
- 服务器是运行态，`output/`、`data/` 以服务器为准；本地重建后从服务器拉数据
