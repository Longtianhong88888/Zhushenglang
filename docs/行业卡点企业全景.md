# 行业卡点企业全景（8 大主题 · 全产业链梳理 v2）

> **用途**：主升浪模型的**追踪范围参考**。模型只追踪行业卡点企业——即掌控某个环节
> 技术、产能、份额或标准主导权的公司，而非全市场所有强势股。
>
> **符号**：⭐ = 已在 `industry_info.csv` 名单（附 pos 分）；其余为建议候选。
> 入名单前需复核基本面、市值与退市风险，并评估 pos 评分。
>
> **口径**：只收 A 股可交易代码（模型可追踪）；港股/未上市卡点单独标注，不入名单。
> 依据：2025-2026 公开信息与行业研报整理；不构成投资建议。
