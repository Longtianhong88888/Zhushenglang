# 大牛模型（固化版）—— 模型说明书

> 2026-08-14 用户确认固化的正式模型：**硬规则·评分≥2 + MA20 退出 + 杀跌区停开**。

## 模型规则（冻结，不可随意改）

1. **追踪范围**：行业卡点企业 **97 只**（110 - 3 只 301 创业板注册制 - 10 只 688 科创板；
   **300 创业板可交易**）
2. **入场**（信号日收盘买入，需同时满足）：
   - 硬规则：**热主题**（AI硬件/半导体/存储）且 **90 日内累计 T0 信号 ≥3**
   - **大牛评分 ≥2**：热主题 +1 ｜ 90日T0≥3 +1 ｜ 创60日新高且10日<30% +1 ｜
     链长≥4（相邻信号间隔≤20日）+1（硬规则下评分天然 ≥2，门槛保证质量下限）
3. **仓位**：单票 **1/3 仓**，最多 **3 只**并行（同日多候选按评分/90日计数降序）
4. **退出**：**收盘跌破 MA20 卖出**；**不手动买回**——等规则再次触发再入场
   （研究结论：企稳买回为负优化，规则再入场即最优"买回"机制）
5. **弱市降档**：大盘等权 20 日涨幅 **≤-5%（杀跌区）不新开仓**；已有持仓按 MA20 纪律退出
6. **费用**：0.2%/笔（双边）

## 研究结论支撑（勿回退的负结果）

- 企稳买回（站回 MA20/加斜率/两日确认）系统性输给"不买回+规则再入场"（+163%~+607% vs +614%）
- 大牛评分是质量过滤器：评分≥3 提高胜率/PF 但降总收益（+670% vs +777%）；评分≥4 过度过滤
- 评分≥2（硬规则下等价于基线）为"收益优先"档；弱市可用评分≥3 收紧（稳健档）
